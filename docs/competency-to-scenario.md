# From Competency to Scenario Intent (Sketch)

Methodology only. One illustrative job family. No item banks, no production stems.

## Purpose

Routing maps assume a typed question. Upstream, products still need:

> Which **competencies** matter → which **scenario intents** elicit evidence → which **type key** owns the follow-up pack.

This note shows a **half-page pattern** for that upstream link. It is not a full JD library.

## Pattern

```text
Role / family
    → 3–5 competencies (observable)
        → each: one scenario intent (what to stress-test)
            → map to a question-type key
                → follow-up owned by that type’s decision map
```

## Illustrative family: frontline service / sales-adjacent

| Competency (observable) | Scenario intent (what the stem should create) | Type key | Follow-up focus (map side) |
|-------------------------|-----------------------------------------------|----------|----------------------------|
| Staying task-focused under pressure | User / client pushes for speed or exception | `situational` | Plan / stance under tension; don’t overgeneralize one probe rule |
| Owning a past conflict outcome | Recall a concrete episode with a difficult other party | `behavioral` | Past evidence; block pure “I would…” |
| Clarifying expectations | Ambiguous request; must check before acting | `situational` or `behavioral` | What they checked; why that choice |
| Recovering after a mistake | Something went wrong mid-task | `behavioral` | Sequence + learning without invented praise |
| Choosing what to escalate | Boundary of personal authority vs handoff | `situational` | Decision rule; safety / policy edge if any |

Exact stems stay private. Public artifact = **intent + type key + follow-up ownership**.

## Anti-patterns

- Writing long essay stems before competencies are fixed  
- One universal follow-up pack for every competency  
- Scoring “attitude” without an observable evidence target  

## Note on other products

Expert-dialogue / companion agents can use the same table shape with different competency rows (e.g. clarifying emotion vs advising action). The **decision-map discipline** (typed packs + exception lanes) still applies; only the competency vocabulary changes.
